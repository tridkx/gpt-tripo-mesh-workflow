# 网格清理、拆分与便于维护的 UV

## 展开前的网格清理

先建立连通分量、边界边和非流形边诊断，检查重复/重叠表面、零面积面及三角形质量。将异常定位到实际部位，与材质和多视图一起判断；不能把所有独立分量、开放边或细长三角形都当作缺陷。保留源面映射、源 UV、材质和角点法线，清理后的表面变化需可追溯。

- **意外断开的面与裂缝：** 检查本应连续的表面是否存在近邻断边、重复未焊接顶点、悬浮碎片或 T 接点。确认邻边位置、方向、法线和部位归属一致后，局部焊接、桥接或修补；容差随模型尺度确定。正常独立的眼球、发片、饰品、衣物内外层及用户要求的开放切口不自动连接。不用全模型 Merge by Distance 将相邻衣物或发片粘在一起。
- **重复或重叠面：** 区分完全重复面、部分共面覆盖、非共面交叉，以及正常叠穿/内外层。完全重复面保留正确材质和朝向的一份；部分共面覆盖可局部裁切、分割并移除冗余区域，同时插值源 UV 和法线。非共面穿插需要单独判断形体，不按投影重叠直接删面。总面积减少不是充分验证，应检查保留表面的覆盖和孔洞。
- **退化或畸形三角形：** 检查重复顶点、近零面积、极短边、尖角、很大的长宽比和异常法线。按局部尺度与曲率判断；合理的尖发梢或弯曲轮廓可包含细长三角形。缺陷优先用局部溶解后重新三角化、换边、合并或有限的局部重拓扑改善，保留轮廓和有用细节。不要只靠全局平滑或直接删掉坏面留下孔洞，也不以全面转四边形作为默认目标。

几何清理在用户要求的网格整理范围内进行；仅重排 UV 的任务先诊断并报告几何障碍，不自行扩大成形体重建。局部修补不足以得到可维护裁片时，明确需要局部或完整重拓扑的部位与代价，不以大量微小 UV 岛替代问题处理。合并或换边后删除退化面，检查法线、材质归属、切口与表面覆盖，再恢复自定义角点法线和展开。

## 拆分

生成三角网格的几何连通性与语义常常不一致：头发与脸可能粘在一起，独立小岛可能是眼球、饰品或衣物碎片。先建立 face adjacency 和连通分量，再按位置、法线变化与参考图识别种子区域。按二面角限制的平滑分量可辅助找衣物边界；带二面角代价的图传播可扩展种子。代价、种子及边界需由当前模型决定，并通过部位颜色预览修正。

空间平面适合简单切口，不适合直接识别衣服和皮肤。若平面穿过三角形，计算交点并插值 UV、法线及已有权重等 corner/vertex 数据，保证切后表面一致。不需要封口时保持开边，不用 remesh 代替拆分。需要封口时另行检查内面、法线和 UV。

角色自身左右由坐标和姿态确认。袖子归上身时，应沿袖口区分衣物和裸露手臂，不能继续使用肩部平面将袖子切到手臂。被衣服遮挡且不存在的身体几何不会因拆分自动产生。

记录源面到输出部位的映射，避免漏面/重复面。对零面积面记录数量与处理理由；阈值按模型尺度选择。拆分前后比较总表面积、包围盒、空间覆盖及法线，颜色预览检查接缝。总面积相等仍可能出现重复一处、遗漏另一处，不能作为唯一检查。

## UV 组织

“规整”首先意味着便于维护：能辨认部位、找到相邻表面，画一段花纹或修改一块颜色时不必追踪许多散落碎片。语义可读、方向一致和接缝合理比外框整齐更重要，不要求所有三角网格展开成矩形。按上衣前后、袖子前后、裤腿、手掌/手背与手指、脚/鞋、脸/颈、主发束/饰品规划连续裁片与大区。

先清除无必要的已有接缝，沿真实边界、内侧、后侧或视觉隐蔽处设置少量有目的的切缝，再展开或投影。保持裁片内部相邻面的 UV 连续；空间上把小岛排在一起并不等于合并。手指尽量保留可辨认的连续片，发束尽量沿长度连贯，不逐三角形切开。按解剖/结构和拉伸情况选择合理裁片数量，不把所有手指或发束强接成一个岛。

投影或展开出现折叠/重叠时，先回查几何缺陷、切缝和展开方式，再尝试调整缝、拼接兼容边界或换局部展开。将问题面逐面移到零碎预留区只能用于少数确有必要的例外；若例外不断增加，应退回上一步处理原因，不能把大量碎岛作为默认最终方案。

只有为控制拉伸、保留独立结构、材质边界或避免不可消除的重叠所必需时才保留小岛。必要的小岛按所属部位集中、方向有序，并保留定位信息；不要无语义地散落在图集空隙。高碎片输入若要求如人工建模衣片一样连续，需要评估重拓扑，不承诺仅重排 UV 就能得到。

复杂头发可逐连通组件比较源裁片与新展开：尝试稳定的投影/展开，比较连续性、小岛数量、拉伸和采样质量，在可接受拉伸与纹理质量下选择更便于维护的方案。保留复杂发髻已有的好裁片，通常比整头统一重展更可靠。合并后的裁片重排时按世界表面积与 UV 面积估计密度，不能把每个小组件都放大成相同矩形。

修补眼角等微小裂缝前，检查实际边界在三维与投影中的自交、折返和重叠。投影边界不一定是简单多边形；直接扇形封补可能产生重叠裁片。局部合并顶点后先删除重复顶点的面和退化面，再恢复 corner normals；将退化面传给自定义法线 API 可能使 Blender 崩溃。

选择贴图方案：独立部位各一张方便修改，单图集或 UDIM 则按目标软件和用户需求安排。不同图片上的 0–1 坐标重合正常。为主要裁片定向，控制纹理密度，为脸/花纹等细节留面积；必要的密度差应记录。根据目标分辨率预留岛间空隙与 bake margin，避免 mipmap 串色。

输出分开的干净颜色画布、透明 UV 线框和带标签区域图；不要把标签或线框烘进颜色贴图。区域元数据可记录对象/材质/图片、裁片名称、目标矩形、面域、UV 与三角形，便于后续生成提示和采样校准。

## 检查

1. 检查 UV 有限值、目标范围、未展开面、零面积 UV。微小真实面和零面积几何要区别处理。
2. 以实际共享图片为单位查三角形重叠，忽略仅边界接触。可用 Shapely + 空间索引求交面积；根据尺度设置数值容差并报告。不允许只对单个对象检查而漏掉多个对象共用同一图片的重叠。堆叠/镜像若是有意设计，应排除且记录。
3. 棋盘格检查正背侧面的拉伸、方向、尺寸差及缝；“无重叠”不代表拉伸合格。
4. 按部位比较整理前后的实际连通 UV 岛数、少面/小面积岛数量与目标分辨率下的像素覆盖，说明小岛判定标准及保留理由。没有通用的固定岛数或小岛比例；不要以总岛数下降掩盖手指、眼角等重点部位仍很碎。几何微小面、UV 零面积和不足以绘制的微小裁片分别报告。
5. 做维护性检查：挑选手指、眼角、衣片或发束等实际修改单元，确认能快速定位并沿连续裁片完成一次局部改色/花纹修改；主裁片接缝合理，必要的小岛能追溯到所属部位。图集利用率、无重叠和岛数统计不能替代这项判断。对剩余难维护区域明确说明，不能直接宣称全部整理完成。
6. 复查几何清理前后的意外断面、冗余重叠、退化/畸形三角形和非流形问题；按部位报告已修与保留内容，检查是否新增孔洞、破坏独立层或改变轮廓。允许的局部形体变化与应保持不变的区域分别验证。
7. 在空场景重新导入 FBX。浮点误差允许适当容差；不要要求导入后浮点逐位一致。若导出器重排面或改变三角化，对表面与每角属性做匹配，不能仅按面列表索引断言资产已损坏。

`audit_mesh.py` 提供基础诊断，**不检测 UV 重叠或拉伸，不证明拆分/导出等价**；这些检查仍需另行执行。
