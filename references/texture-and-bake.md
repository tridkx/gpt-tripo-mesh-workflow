# 参考图贴图与烘焙

## 本项目采用的贴图路线

依据人物参考图新制或重做外观时，执行 **UV 指引驱动的平面贴图生成、局部校准与烘焙**。不把人物参考图本身当作相机投射纹理，不默认使用正背侧照片直接投射、按面朝向混合参考照片或多视角照片投图。用户明确要求直接投射参考图时才改用该方案，并单独检查遮挡、透视、光照与视图接缝。缺少图像生成能力时说明缺失，不悄悄切换为参考图投射。

1. **确定主 UV。** 新制外观前，按网格/UV 参考整理可维护的裁片，并确定贴图分区。本项目按六部位各用一张图；其他资产按实际部位和材质安排，不强制六张。只要求修改现有贴图时保留主 UV，不擅自重新展开。
2. **输出生成指引。** 为每张图提供对应 UV 线框、带标签的区域图，以及人物正背侧等参考图。注明前后、角色自身左右、皮肤与衣物、虹膜/眉毛/嘴等实际面域。UV 指引限定裁片位置和方向；人物参考图提供颜色、衣料、花纹与五官风格，背景与人物轮廓不进入最终图集。
3. **生成平面 BaseColor。** 使用 imagegen 按部位生成/编辑可直接用于主 UV 的平面贴图。提示词明确裁片对应关系、布局、颜色与纹理方向，要求最终图不带标签、线框、人物立绘、场景背景、强烈照明阴影或 3D 效果展示。模型本身已有褶皱时，避免贴图再画强烈褶皱阴影。保存原始输出、提示词和实际尺寸；一次全身复杂图集容易错位，按部位制作并单独检查脸部。
4. **上模检查与局部校准。** 将生成的平面图接到模型材质，渲染正背侧与局部近景。布局偏差用临时采样 UV 对生成图作移动、缩放或分段映射，独立虹膜、嘴和颈等按实际面域单独校准。源图始终是生成的平面贴图，不能借此改成采样整张人物参考照片。纯色皮肤、鞋、花饰等必要区域可用材质分区常量校色；有细节的面域保留其纹理。
5. **烘焙固定结果。** 用 Cycles EMIT 将校准后的生成贴图与必要的分区颜色烘焙到主 UV 对应的新图片。最终材质只需主 UV 与最终 PNG；移除临时采样层和校色节点。按下文核对色彩空间、贴图打包、外部 PNG 与 FBX 回读。

提示词中的精确矩形和 UV 指引只能帮助生成，不能保证像素遵循。必须检查实际结果尺寸，并将生成纹理上模检查。内置工具生成/编辑遵循 imagegen skill，不用 Pillow 或程序重绘冒充 AI 图像编辑。Blender 为模型映射进行采样/烘焙是本流程的配准步骤。

### 已有贴图与后续修订

有可用原贴图且只整理 UV 时，保留源 UV、源图和源材质，将原颜色烘到新 UV，不重新生成外观。对已完成贴图进行局部修订时，优先编辑对应平面贴图或局部采样/分区颜色，保留其余区域；需要 AI 图像修改时继续使用 imagegen。重排 UV 后也是转移已有颜色，不重新投射人物参考图。

### “投影”术语的区分

| 操作 | 在本流程中的用途 |
|---|---|
| 将网格面域投影到二维 | 制作局部 UV 的方法之一，需检查连续性、拉伸和重叠；不是参考图上色方式 |
| 用模型坐标或临时 UV 采样生成的平面贴图 | 允许用于局部配准，再烘焙回主 UV；本项目脸部曾使用这类校准 |
| 从相机/视角将整张人物参考图投到模型 | 用户明确选择时才使用，不作为本 skill 的默认上贴图路线 |

## 校准

面部先识别真实几何：虹膜可能是独立盘状组件，眉毛可能有几何，嘴可能有内层。不能因为脸部 atlas 看起来有眼睛就认定虹膜几何已采样正确。

眉毛与睫毛都可能是独立薄片，必须结合实际位置和渲染识别；不能仅凭组件面数或“位于眼睛上方”删除。眼角黑点可来自真实裂缝露出后侧头发，也可来自颜色污染，先用材质诊断或射线区分。大块平面眼白补片容易盖住虹膜或形成突出的白斑，应先评估局部边界修复与原眼睛贴图调整。

用户只想扩大虹膜周围的眼白时，可在已识别的虹膜面域内，对源采样 UV 围绕实际虹膜中心轻微放大，再烘焙到目标 UV；源采样放大意味着图案在模型上缩小。限制采样在对应眼睛图块内，越界用匹配的眼白颜色处理，避免串入邻近眼睛或皮肤。不能用全局亮度阈值将虹膜下部亮纹或高光误刷成眼白；必要的颜色清理限定在已确认的外围区域，并保留原纹理与高光。检查双眼近景与斜侧面，不默认沿用某个案例的中心、比例或颜色。

错位可用临时 UV 或可控材质采样重定位：原主 UV 用作目标，另建采样 UV 表示来源。依据当前模型位置和生成图中的实际五官建立映射；衣片可采用区域级平移缩放，脸部常需分段映射或独立眼/嘴面域。不要复制旧案例五官坐标。

眉毛重影可能来自面部贴图与独立眉几何重复；脖子条纹可能是跨越嘴部颜色的插值；鞋上的裤料可能来自区域分类或 UV 采样错误。先定位错误发生在几何面域、采样还是生成素材，再修对应环节。不要通过统一模糊、全局减饱和掩盖。

面域常量校色适合纯色小配件或鞋，不适合抹掉应保留的细节。若用 CORNER 属性或额外材质选择区域，边界按实际面分配；顶点线性插值可能跨区域泄漏。

## Blender bake

使用 Cycles 的 EMIT bake 转移 BaseColor，避免把场景灯光烘进颜色。需要传递色彩时让源采样连接 Emission，再设目标 Image Texture 节点为 active。目标与来源图片不能是同一个写入图，避免反馈。多材质的每个槽需设有效目标节点。

显式确定主 UV 为烘焙目标；来源 Image Texture 用 UV Map 节点指定临时采样 UV，避免两者意外使用同一 active UV。既有源 UV 烘到新 UV 同理。根据图片尺寸设 margin，并检查 sRGB/Non-Color 用途及色彩空间，常量颜色与图片像素的数值不一定可直接等同。

保存 PNG 后建立最终简单材质，移除临时采样层、选择属性和校色节点，最终图连接 Base Color。只在验证目标图已正常读取后清理来源。将贴图打包到 BLEND，FBX 用支持的嵌入设置并重新导入验证；保留外部 PNG 便于软件兼容和修改。

## 迭代停止条件

生成 → 上模 → 定位错误 → 局部配准/必要时重新生成 → 烘焙 → 上模复查。优先修正五官错位、跨区串色、缝隙和明显重复花纹。完成正背侧与面部近景检查，再进行最终导出核对。不要因 atlas 美观而跳过上模，也不因原几何限制无止境重生成纹理。

交付区分 BaseColor、normal、roughness 等实际生成通道；只做颜色图不能宣称完整 PBR。烘焙放大到 2K 不代表原生成图有 2K 细节。脸部外形与衣物版型受原几何约束，贴图不能保证参考图形体的一比一还原。
